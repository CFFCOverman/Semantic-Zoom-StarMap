# 文件结构即架构
文件夹结构就是模块结构。这个文件是硬性规定。
1. **一个文件夹 = 一个模块（scope）；文件是最小的单位：** 文件里的节只是这个文件的内容，不能截出来单独当一个单位。东西放哪，由它属于哪个模块决定。
2. **每个文件夹最多一个头脑文件：** 普通文件夹用 README.md（写给人看），skill 文件夹用 SKILL.md（写给 AI，开头的 name 和 description 决定何时加载）。头脑文件是这个 scope 的 L0：写清模块干什么、接口是什么、下面有哪些节点，每个节点一行职责并链接到它。根目录和 skill 文件夹必须有：根目录的头脑文件告诉 AI 这个系统干什么、从哪看起（AI 读文件干活，不看星图）；skill 文件夹必须有 SKILL.md，否则它不算一个 skill。其他文件夹可有可无，没有时按默认处理：这个文件夹下的文件和子文件夹就是它的节点，它的职责取上一层头脑文件里列它的那一行，没有就留空。
3. **其余文件是节点：** 每个文件只讲头脑里列出的一个节点，不复写头脑里的定义。
4. **子文件夹是子模块：** 同样有自己的头脑文件（没有时按第 2 条的默认），一层套一层。
5. **不放两个头脑：** skill 文件夹里若要 README，只写一句「见 SKILL.md」。
6. **层级按位置和文件种类分：** 哪个文件属于 L0 到 L3 的哪一层，见 layers.md § 层级。要调整就挪文件或文件夹，再同步星图（见 starmap.md § 星图清单）。
